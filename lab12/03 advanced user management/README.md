# Повышенный уровень — управление пользователями
Запуск: `npm install`, затем `npm start`. Откройте http://localhost:3003.
Аккаунты: admin / admin123; student / 12345; teacher / 12345.
Есть роли admin/student/teacher, защищённые API, создание и отключение пользователей, журнал входов/выходов и отказов, защищённый ресурс.
Важно: учебный прототип. Данные и пароли хранятся в памяти в открытом виде и сбрасываются при перезапуске. Для production нужны БД, хеширование паролей, HTTPS, постоянное хранилище сессий, CSRF-защита и ограничение попыток входа.

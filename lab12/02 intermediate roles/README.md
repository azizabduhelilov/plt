# Средний уровень — две роли
Запуск: `npm install`, затем `npm start`. Откройте http://localhost:3002.
Аккаунты: `student` / `12345`; `teacher` / `12345`.
Студент и преподаватель получают разные страницы. Серверный middleware проверяет роль: 401 без входа, 403 при неверной роли. Есть выход и восстановление сессии.

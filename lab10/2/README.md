# Средний вариант №8 — Список задач

## Запуск
В терминале из папки проекта: `python -m http.server 8000`. Откройте `http://localhost:8000`.

## Структура модулей
- `tasks.js` — модель и операции добавления, переключения статуса и удаления.
- `ui.js` — отрисовка списка и сообщения.
- `main.js` — связывает форму, события и модули.

## Проверки
| № | Сценарий | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | Добавить «Подготовить отчёт» | Задача появляется в списке | Соответствует |
| 2 | Отправить пустую форму | Появляется предупреждение | Соответствует |
| 3 | Отметить задачу выполненной | Текст зачёркнут, счётчик обновлён | Соответствует |
| 4 | Удалить задачу | Задача исчезает | Соответствует |
| 5 | Нажать «Удалить выполненные» | Выполненные задачи удаляются | Соответствует |

## Вывод
Реализован список задач с разделением модели, отображения и управления событиями. Модули взаимодействуют через named export/import, интерфейс обновляется после каждого действия.

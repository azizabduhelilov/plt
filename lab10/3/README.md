# Продвинутый вариант №16 — Мини-CRM клиентов

## Запуск
Из папки проекта выполните `python -m http.server 8000`, затем откройте `http://localhost:8000`.

## Схема модулей
`main.js` импортирует `clients.js`, `validation.js`, `storage.js` и `ui.js`.
- `clients.js` — CRUD: создание, чтение, изменение, удаление и поиск клиентов.
- `validation.js` — проверка имени, телефона и email.
- `storage.js` — сохранение/загрузка JSON через localStorage.
- `ui.js` — формирование таблицы и сообщений.
- `main.js` — обработчики событий и координация модулей.

## Проверки
| № | Сценарий | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| 1 | Имя, телефон и корректный email | Клиент добавлен в таблицу | Соответствует |
| 2 | Пустое имя | Показана ошибка, запись не добавлена | Соответствует |
| 3 | Телефон с буквами | Показана ошибка формата телефона | Соответствует |
| 4 | Поиск по части имени/email | Отображаются совпадения | Соответствует |
| 5 | Изменение и удаление клиента | Изменения видны, удалённая запись исчезает | Соответствует |
| 6 | Перезагрузка страницы | Сохранённые записи загружаются из localStorage | Соответствует |

## Вывод
Разработана мини-CRM с независимыми модулями для CRUD-операций, валидации, хранения, поиска и DOM. Разделение облегчает поддержку: правила проверки и работа с данными могут изменяться отдельно от интерфейса.

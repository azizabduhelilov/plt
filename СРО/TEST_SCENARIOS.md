# Тестовые сценарии

Тестирование выполняется вручную в браузере после открытия `index.html`.

| № | Сценарий | Действия | Ожидаемый результат |
|---|---|---|---|
| 1 | Первое открытие | Открыть приложение без сохраненных данных | Баланс, доходы и расходы равны 0 ₸; отображается пустое состояние |
| 2 | Добавить расход | Описание «Продукты», сумма 5000, категория «Продукты», сегодняшняя дата | Расходы = 5 000 ₸, баланс = −5 000 ₸, запись отображается в списке |
| 3 | Добавить доход | Доход «Зарплата» на 100 000 ₸ | Доходы = 100 000 ₸; при расходе 5 000 ₸ баланс = 95 000 ₸ |
| 4 | Нулевая сумма | Ввести 0 и сохранить | Запись не добавляется, появляется сообщение о некорректной сумме |
| 5 | Отрицательная сумма | Ввести −100 | Запись не добавляется |
| 6 | Дробная сумма | Ввести 10,5 | Запись не добавляется, так как сумма должна быть целой |
| 7 | Пустое описание | Оставить описание пустым | Браузер требует заполнить поле; запись не создается |
| 8 | Дата в будущем | Выбрать будущую дату | Выбор ограничен атрибутом max; если значение передано вручную, валидация отклоняет его |
| 9 | Поиск | Добавить несколько операций, ввести «продукты» | Остаются операции, в описании или категории которых есть этот текст |
| 10 | Фильтр типа | Выбрать «Доходы» | Отображаются только доходные операции |
| 11 | Отчет категорий | Добавить расходы в двух категориях | Отчет показывает сумму и долю каждой категории; проценты соответствуют общей сумме расходов |
| 12 | Удаление | Нажать × и подтвердить | Запись удалена, сводка и отчет пересчитаны |
| 13 | Отмена удаления | Нажать × и отменить подтверждение | Запись остается в списке |
| 14 | Сохранение | Добавить запись и перезагрузить страницу | Запись остается, если браузерное хранилище не очищено |
| 15 | Мобильный экран | Открыть страницу на узком экране | Интерфейс адаптируется, таблицу можно прокручивать по горизонтали |

## Критерий успешного прохождения
Сценарий считается пройденным, если фактическое поведение соответствует ожидаемому результату. Для демонстрации рекомендуется выполнить сценарии 1, 2, 3, 9, 11 и 14.

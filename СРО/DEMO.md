# Демонстрация результата

## Подготовка
1. Откройте `index.html` в браузере.
2. Убедитесь, что на первом запуске сводка показывает нулевые значения.
3. Для чистого повторного показа удалите предыдущие тестовые записи или очистите хранилище сайта.

## Пример демонстрации
1. Нажмите «Добавить операцию».
2. Добавьте расход: описание `Продукты`, сумма `5000`, категория `Продукты`, дата — сегодня.
3. Добавьте расход: описание `Проезд`, сумма `1000`, категория `Транспорт`, дата — сегодня.
4. Добавьте доход: описание `Стипендия`, сумма `40000`, категория `Стипендия`, дата — сегодня.

После этих действий приложение должно показать:
- **Доходы:** 40 000 ₸
- **Расходы:** 6 000 ₸
- **Баланс:** 34 000 ₸
- **Продукты:** 5 000 ₸ (примерно 83% расходов)
- **Транспорт:** 1 000 ₸ (примерно 17% расходов)

Затем продемонстрируйте поиск по слову «Проезд», фильтр «Доходы», удаление одной записи и перезагрузку страницы для проверки сохранения данных.

## Что объяснить преподавателю
- Почему выбрано браузерное приложение: легко запустить, не требуется установка и сервер.
- Где используются массивы: массив `transactions` хранит финансовые операции.
- Где используются функции: отдельные функции обновляют сводку, таблицу, отчет и проверяют ввод.
- Где обрабатываются строки: поиск без учета регистра, обрезка пробелов, форматирование даты.
- Как хранятся данные: массив преобразуется в JSON и записывается в `localStorage`.
- Как устроен жизненный цикл: анализ требований → проектирование → реализация → тестирование → внедрение → сопровождение.

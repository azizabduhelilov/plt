# Учет личных расходов

Учебный проект по предметной области «Финансы». Приложение позволяет учитывать доходы и расходы, рассчитывать баланс и просматривать структуру расходов по категориям.

## Запуск
1. Распакуйте папку проекта.
2. Откройте `index.html` в современном браузере (Chrome, Edge, Firefox или Safari).
3. Нажмите «Добавить операцию», заполните поля и сохраните запись.
4. Данные сохраняются в `localStorage` текущего браузера. Сервер и установка библиотек не требуются.

## Возможности
- добавление доходов и расходов;
- автоматический расчет общего дохода, расхода и баланса;
- категории операций, отдельные для доходов и расходов;
- отчет по расходам: сумма и процент каждой категории;
- поиск по описанию и категории, фильтр по типу;
- удаление операций с подтверждением;
- проверка описания, суммы, категории и даты;
- сохранение данных между перезапусками браузера.

## Структура проекта
- `index.html` — разметка интерфейса и форма добавления операции;
- `styles.css` — оформление и адаптация для мобильных экранов;
- `app.js` — модель данных, бизнес-логика, валидация, хранение и отчеты;
- `PROJECT_REPORT.md` — анализ предметной области, пользователей, жизненного цикла и модели данных;
- `TEST_SCENARIOS.md` — тестовые сценарии;
- `DEMO.md` — инструкция для демонстрации результата.

## Технологии
HTML5, CSS3, JavaScript (ES6+), DOM API, `localStorage`, `Intl.NumberFormat`.

## Примечание
Это учебное приложение: данные хранятся только локально в конкретном браузере и не синхронизируются с банком или другими устройствами. Для очистки демонстрационных данных удалите операции кнопкой × либо очистите данные сайта в настройках браузера.

# Тестовые сценарии

Выполняются вручную в браузере после открытия `index.html`. Основные сценарии (1–19) также проверены автоматически в Chromium.

| № | Сценарий | Действия | Ожидаемый результат |
|---|---|---|---|
| 1 | Первое открытие | Открыть приложение без данных | Всё по нулям, показано пустое состояние с кнопками |
| 2 | Добавить расход | «Продукты», 5000, категория «Продукты», сегодня | Расходы = 5 000 ₸, баланс = −5 000 ₸ |
| 3 | Добавить доход | «Стипендия», 40000 | Доходы = 40 000 ₸, баланс = 35 000 ₸, норма сбережений 88% |
| 4 | Нулевая сумма | Ввести 0 | Запись не добавляется, сообщение об ошибке |
| 5 | Отрицательная сумма | Ввести −100 | Запись не добавляется |
| 6 | Дробная сумма | Ввести 10.5 | Запись не добавляется (нужно целое число) |
| 7 | Пустое описание / сумма | Оставить поле пустым | Сообщение об ошибке, запись не создаётся |
| 8 | Дата в будущем | Выбрать завтрашнюю дату | Дата ограничена; вручную введённая отклоняется |
| 9 | Редактирование | «Карандаш» у записи, изменить сумму | Запись и сводка обновлены |
| 10 | Поиск | Ввести часть описания или категории | Остаются подходящие записи |
| 11 | Фильтр типа и категории | Выбрать «Доходы», затем категорию | Показаны только подходящие операции |
| 12 | Сортировка | «Сумма: по убыванию» | Список без группировки по дням, от большей суммы к меньшей |
| 13 | Период | Переключить «Неделя / Месяц / Год / Всё время» | Сводка, диаграмма и список пересчитаны, заголовок периода обновлён |
| 14 | Кольцевая диаграмма | Расходы в двух категориях | Показаны суммы и доли, в сумме около 100% |
| 15 | Бюджет | Задать лимит 10 000 при расходах 5 000 | Прогресс 50%, остаток 5 000 ₸, подсказка «в день» |
| 16 | Превышение лимита | Лимит меньше расходов | Красный индикатор и сообщение о перерасходе |
| 17 | Удаление | Корзина → «Удалить» | Запись удалена, всё пересчитано |
| 18 | Отмена удаления | Корзина → «Отмена» | Запись остаётся |
| 19 | Сохранение | Перезагрузить страницу | Данные и лимит на месте |
| 20 | Экспорт CSV | «Данные → Экспорт в CSV» | Скачан файл, открывается в Excel с кириллицей |
| 21 | Резервная копия | Экспорт JSON → очистить всё → импорт | Операции восстановлены, дубликаты не создаются |
| 22 | Неверный файл | Импортировать не-JSON файл | Сообщение об ошибке, данные не изменены |
| 23 | Пример данных | «Загрузить пример» | Появляются операции за 6 месяцев, графики и лимит |
| 24 | Тёмная тема | Кнопка темы, перезагрузка | Тема переключается и запоминается |
| 25 | Мобильный экран | Ширина 390 px | Нижняя навигация, кнопка «+», нет горизонтальной прокрутки |
| 26 | Горячие клавиши | `N` и `/` вне полей ввода | Открывается форма / фокус на поиске |

## Критерий успешного прохождения
Фактическое поведение совпадает с ожидаемым. Для демонстрации рекомендуется: 1, 2, 3, 9, 13, 14, 15, 21, 23.

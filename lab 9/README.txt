ЛАБОРАТОРНАЯ РАБОТА №9 — Fetch API / AJAX
Студент: Абдухелилов Азиз
Группа: ИС 25 - 22

В архиве три независимых проекта:
1 — базовый уровень, вариант 1: первые 10 публикаций, ID и заголовки.
2 — средний уровень, вариант 8: загрузка публикаций и клиентский поиск по заголовку.
3 — повышенный уровень, вариант 18: параллельная загрузка /users и /posts через Promise.all(), подсчёт публикаций каждого пользователя и сортировка.

Запуск:
1. Распакуйте архив.
2. Откройте нужную папку в VS Code.
3. Запустите index.html через расширение Live Server (рекомендуется).
4. Нажмите кнопку загрузки. Для работы нужен интернет и доступ к JSONPlaceholder.

Во всех проектах используются fetch(), async/await, проверка response.ok, try/catch/finally и безопасное добавление данных через textContent/DOM API.

Тестирование для отчёта:
1. Обычная загрузка — данные должны появиться на странице.
2. Отключить интернет и повторить запрос — должно появиться сообщение об ошибке.
3. Включить интернет и нажать кнопку повторно — загрузка должна восстановиться.
4. Средний уровень: ввести часть заголовка — список должен отфильтроваться; случайный запрос — показать сообщение об отсутствии совпадений.
5. Повышенный уровень: переключить сортировку — карточки должны поменять порядок.

Схема работы:
Действие пользователя → fetch-запрос → проверка HTTP-ответа → разбор JSON → создание DOM-элементов → отображение результата.

Вывод:
В ходе лабораторной работы изучена отправка асинхронных HTTP-запросов с Fetch API, обработка JSON-ответов и динамическое обновление DOM без перезагрузки страницы. Реализована обработка состояний загрузки и ошибок, а на среднем и повышенном уровнях добавлены поиск и параллельная загрузка данных.

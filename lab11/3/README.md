# Продвинутый уровень — вариант 16: Планировщик расходов

Это самостоятельный React-проект. Он содержит только данное задание, а не объединённое приложение.

## Запуск
```bash
npm install
npm run dev
```

Для production-сборки: `npm run build`.

## Состав
- `src/App.jsx` — корневой компонент задания.
- `src/styles.css` — оформление.
- Компоненты задания находятся в `src/`.

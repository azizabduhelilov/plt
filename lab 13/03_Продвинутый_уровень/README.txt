ПРОДВИНУТЫЙ УРОВЕНЬ — Вариант 16 «Планировщик задач»

Запуск сайта: откройте index.html в браузере.
Запуск Python: python lab13.py

Реализовано:
- две очереди: срочная и обычная;
- добавление задач с выбором приоритета;
- обслуживание срочных задач в первую очередь;
- FIFO внутри каждого уровня приоритета;
- безопасная обработка пустых очередей;
- дополнительная функция: история выполненных задач и статистика.

Структуры данных: две collections.deque. Они позволяют эффективно добавлять элементы в конец и извлекать первый элемент. Разделение на две очереди обеспечивает приоритет срочных задач.
Тесты:
1. Добавить обычную и срочную — первой выполняется срочная.
2. Добавить две срочные — выполняются в порядке поступления.
3. При пустой срочной очереди — выполняется первая обычная.
4. Обе очереди пусты — выводится сообщение, программа не завершается с ошибкой.
5. Добавить задачу с пустым названием — операция отклоняется.

ЛАБОРАТОРНАЯ РАБОТА №13 — КОЛЛЕКЦИИ И СТРУКТУРЫ ДАННЫХ

Внутри три самостоятельных проекта:
01_Начальный_уровень — Вариант 1, список покупок (list).
02_Средний_уровень — Вариант 8, система заказов (collections.deque).
03_Продвинутый_уровень — Вариант 16, планировщик задач (две collections.deque).

Каждый проект содержит:
- index.html — сайт;
- style.css — оформление;
- app.js — интерактивность;
- lab13.py — реализация на Python;
- README.txt — описание и тест-кейсы.

Чтобы посмотреть сайт, откройте index.html нужного уровня в браузере.
Чтобы запустить Python-реализацию, откройте терминал в папке проекта и выполните:
python lab13.py

Сайты работают локально и не требуют установки библиотек.

НАЧАЛЬНЫЙ УРОВЕНЬ — Вариант 1 «Список покупок»

Запуск сайта: откройте index.html в браузере.
Запуск Python: python lab13.py

Реализовано:
- добавление товара;
- удаление товара по названию;
- просмотр списка;
- обработка пустого списка и отсутствующего товара;
- проверка повторов;
- дополнительная функция: отметка купленных товаров и статистика.

Структура данных: list. Список подходит, так как хранит упорядоченные элементы и позволяет добавлять/удалять товары.
Тесты:
1. Добавить «Молоко» — товар появляется в списке.
2. Добавить пустую строку — отказ, список не меняется.
3. Добавить «молоко» повторно — отказ от дубликата.
4. Удалить «Хлеб», которого нет — сообщение/отказ без ошибки.
5. Удалить существующий товар — товар исчезает из списка.

СРЕДНИЙ УРОВЕНЬ — Вариант 8 «Система заказов»

Запуск сайта: откройте index.html в браузере.
Запуск Python: python lab13.py

Реализовано:
- добавление заказов в очередь;
- обслуживание первого заказа по FIFO;
- поиск по номеру среди ожидающих и обработанных;
- отчёт об оставшихся заказах;
- проверка пустой очереди и уникальности номера;
- дополнительная функция: журнал обработанных заказов и статистика.

Структура данных: collections.deque — эффективная очередь с добавлением справа (append) и извлечением слева (popleft).
Тесты:
1. Добавить два заказа — оба отображаются в очереди.
2. Обслужить первый — извлекается самый ранний заказ.
3. Обслужить пустую очередь — операция безопасно отклоняется.
4. Найти существующий номер — заказ находится.
5. Найти неизвестный номер / добавить повторный ID — корректное сообщение/отказ.
